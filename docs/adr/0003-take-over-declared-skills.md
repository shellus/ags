# 0003：首次应用接管环境仓库声明的同名 Skill

`env apply` 将环境仓库声明的同名非托管 Skill 计为 `takeover`，在确认应用后备份并替换该目录，同时写入 AGS 管理标记；未被环境仓库声明的普通非托管目录保持不变。若 Skills 根路径是旧符号链接、Windows 目录联接或文件，AGS 先在同一父目录中重命名保留该入口，再建立普通受管目录，因此失败时可以恢复原入口且不会遍历或删除其链接目标。

Agent npm 安装是先于文件事务执行的外部收敛动作。已经成功的升级不会因后续指令或 Skill 应用失败而降级；文件事务仍完整回滚，下一次应用从实际已安装版本继续。这避免 Windows 正在运行的 Agent 可执行文件在无意义的降级中触发锁冲突。
